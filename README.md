# clampchord

Clamp CSV/TSV chord tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/clampchord/

## Install / run

```bash
git clone https://github.com/theworker02/clampchord.git
cd clampchord
node src/cli.js
node --test
```
